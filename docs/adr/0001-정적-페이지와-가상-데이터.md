# ADR 0001 — 정적 페이지와 가상 데이터

- 상태: 승인 · 2026-11-25 (요구 확정 · 설계 승인)
- 근거: 이전 시제품들과 같은 방식, 지원 일정(채용 시 마감 공고)

## 결정

GitHub Pages 정적 페이지로 만든다. 가상 폰 · 요금제 · 손익 가정값을 파일 하나에 넣고, 화면에서 바꾼 값은 보는 사람 브라우저에만 둔다. 서버 · 외부 API · 실제 결제 · 본인 확인은 쓰지 않는다.

## 이유

- 심사자가 링크를 열 때마다 같은 시연이 나와야 한다.
- 요금 · 키 관리 · 개인정보 전송 위험이 없다.
- 화면 2개로 줄인 범위를 짧은 일정 안에 끝낼 수 있다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 작은 서버 + DB | 배포 · 비용 · 일정 부담, 시연 가치가 크지 않음 |
| 화면 설계서(그림)만 | 총액 비교 · 손익 계산이 실제로 맞는지 보여 줄 수 없음 |
| 스프레드시트 계산기 | 손님 화면과 같은 설정값을 쓰는 연결을 보여 줄 수 없음 |

## 결과

- 가격 · 손익 규칙은 순수 함수로 만들어 시험한다.
- 숫자는 가상 · 가정이라 성과가 아니다. 화면과 문서에 그렇게 적는다.
