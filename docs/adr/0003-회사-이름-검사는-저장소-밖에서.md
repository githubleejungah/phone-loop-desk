# ADR 0003 — 회사 이름 검사는 저장소 밖 스크립트로

- 상태: 승인 · 2026-11-25 (설계 승인)
- 근거: 요구 A8, AC-04

## 결정

공개 저장소에 지원 회사 이름이 0번 나오는지 검사하는 스크립트와 금지 단어 목록은 저장소 밖 지원 폴더에 둔다. push 전에 그 스크립트를 이 저장소에 대고 돌린다.

## 이유

- 금지 단어 목록을 저장소에 넣으면 그 목록이 곧 회사 이름 노출이다.
- 인코딩해서 넣어도 풀어 볼 수 있다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 저장소 시험에 목록을 그대로 넣기 | 이름이 드러남 |
| base64 등으로 숨겨 넣기 | 쉽게 풀림 |
| 검사하지 않고 눈으로 보기 | 빠뜨리기 쉬움 |

## 결과

- 저장소의 `node --test`에는 이름 검사가 없다. README에 "공개 전 별도 검사"라고 적는다.
- 공개 승인 요청 때 검사 결과(0건)를 함께 보인다.
