# ADR 0002 — 손잡이 4개만 저장하고 두 화면이 함께 읽음

- 상태: 승인 · 2026-11-25 (설계 승인)
- 근거: 요구 A1 · A6 · A7, AC-12 · AC-13 · AC-21

## 결정

담당자가 바꾸는 손잡이 4개(기기료율 · 처분율 · 회수율 · 손실률, 정수 %)만 localStorage `pld:v1:knobs`에 저장한다. 두 화면은 이 값 하나를 읽고, 모든 금액은 `core/pricing.js`가 매번 계산한다. 손님 선택은 저장하지 않는다.

## 이유

- 금액을 저장하지 않으면 두 화면 가격이 어긋날 길이 없다.
- 손님 선택을 남기지 않으면 개인정보 걱정이 없다. 시연을 처음부터 다시 하기도 쉽다.
- 손잡이를 정수 %로만 받으면 반올림 결과가 흔들리지 않는다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 계산한 가격표를 저장 | 손잡이와 가격표가 어긋날 수 있음 |
| 손님 선택도 저장 | 시연마다 지워야 하고, 저장할 이유가 없음 |
| 소수 % 허용 | 100원 반올림 경계에서 소수 오차 위험(요구 A6) |

## 결과

- 새로고침하면 손님 화면은 처음 단계로, 손잡이는 마지막 저장값으로 열린다.
- 저장이 막힌 브라우저에서는 손잡이도 새로고침 때 기본값으로 돌아간다(안내 1줄).
